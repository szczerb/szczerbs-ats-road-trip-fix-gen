# Deep helper provenance review

**History note:** repository commit IDs in this document are pre-cleanup identifiers; use the [old-to-new mapping](HISTORY_CLEANUP.md#commit-identifiers). Upstream object IDs and artifact checksums are unchanged.

**Observed locally — 2026-10-18; baseline `d2e7d9c59ca8c72ca31f5962ce72e5745792bf93`.** This is a technical comparison of the 29 tracked `src/ats_road_trip/*.py` modules and 25 tracked `tests/test_*.py` files against the retained, ignored TruckLib research copies. It is not a legal conclusion, a clean-room claim, or a proof that no earlier or unretained source was consulted. The authors expressly used third-party C# source for format research. The existing [public repository review](PUBLIC_REPOSITORY_REVIEW.md) covered three parser areas; this review extends the scope to the helper and planner code, tests, and introduction history. It evaluates expression separately from binary-layout facts. A port can be derivative even when it changes language; conversely, matching offsets and constants are weak evidence of expressive copying.

**Observed locally.** I compared function structure, conditions, mutation strategy, comments, and representative source bytes by direct reading; reviewed `git show` at the first introducing commit and later diffs; inventoried all production and test paths; and checked retained source blobs against saved tree metadata. I did not use a numerical similarity score: common type names, fields, record orders, and boilerplate would dominate one. I did not run ATS or change a profile. Current Git state and inspected source may change after this baseline.

## Historical trace and assessment

**Observed locally.** The first tracked tool-code commit `f5162ea` (2026-10-17 14:40 Warsaw time) already contains `ppd.py`, `archive.py`, `sii.py`, and early `package.py`. `4a61528` adds `local_fuel.py`; `6158941` adds `overlap_fuel.py`; `0e5b6c9` adds the later PPD upgrader and expands package/archive support; `defa832` adds `rest_stops.py`; `93a2aed` extends rest handling and adds courier eligibility. The local sector-parser copy directory is named `2026-10-17_22-11-10`, between overlap's commit and the broad map generator commit. Directory naming is not proof of download time or of what an author had already read online. `git show` of the earliest PPD helper already contains its selective parser/clone shape, so no later rewrite concealed an earlier C#-like implementation in tracked history. The initial source comparison cannot prove independent creation because upstream code was consulted.

**Technical conclusion, medium-high confidence for the now compared historical sources.** Across the retained and newly verified C# set, I found shared binary layouts, enum/flag semantics and one compact token formula, but no substantial line-by-line translated helper, matching unusual comments, or nontrivial copied control-flow sequence in the reviewed Python helper and planner functions. The token encoder remains the clearest narrow similarity: it implements exactly the upstream positional polynomial, with distinct validation and code organization. That is likely shared schema math on technical evidence, while possible expressive adaptation of the tiny formula remains a legal judgment. Exact saved-tree `Token.cs`, `Trigger.cs`, and `TriggerPoint.cs` have now been compared; unretained Blender Tools revision and other possibly consulted sources still limit the global conclusion. If a reviewer finds protected adaptation, isolate the implicated function/module and choose a compatible licensing or replacement path; do not assume that changing syntax, removing attribution, or rewriting history cures provenance. The 19 verified historical blobs establish the inspected GPLv2 license/README baseline without requiring a containing commit ID to identify their bytes. A public release still needs the intended root license selected, applicable notices retained, and separate rights review for source-owned map/game output. Permission for later GPL versions remains unverified.
