## Experimental variant identity

**Documented — user feedback, 2026-10-19:** the Dawson r0 alternatives had identical descriptions and long titles whose trailing method/filename distinction was hidden by Mod Manager truncation. The user could switch them without restarting ATS but could not identify which experiment produced a result. Installing both files and activating only one is valid for this handoff; folder presence does not mean both are enabled.

Every new set of alternatives must use stable, readable identifiers at the **beginning** of the title, filename and first description line. Include the method or test area and the enable-one-versus-enable-together rule. Do not depend on Mod Manager order or filesystem timestamps; the sorting cause is not established by the screenshots. Keep full source identity and the experimental qualifier elsewhere in the metadata.

The corrected station identities are **A LINES** (`painted_bays`, source-model separator inference) and **B GEOMETRY** (`unmarked_geometry`, building/lot geometry). Their filenames start `a-lines-` and `b-geometry-`. The prefix describes the algorithm, not proof that painted lines are visible in the actual profile. The [Dawson follow-up](GAS_STATION_CAR_REST_FEEDBACK_2026_10_19.md) records actual runtime attribution, active model differences and metadata-only archive audits. Original packages remain historical evidence; new labelled copies must preserve every gameplay member byte-for-byte.

## Historical fuel-package contract

| Field | Value / rule |
| --- | --- |
| Display name | `szczerb's Road Trip Gas Stations Fix for <short map name>` |
| Initial map name | `ATS Expansion` (omit the source mod's version from the short label) |
| Author | `szczerb` |
| Package version | `1.61-r0-experimental` initially; major/minor derived from declared ATS version, revision explicit |
| Compatible versions | `1.61.*`; a UI gate, not a claim that source-pinned sector recipes support every patch |
| Category | `map` |
| DLC dependency | `dlc_rt_ford` for the currently investigated Road Trip baseline |
| Icon | Optional root `mod_icon.jpg`, JPEG, exactly 276x162 pixels |
| Description | UTF-8 `mod_description.txt`, including experimental scope and source-map load priority |

The three historical fuel generation commands require `--map-name`, accept `--revision` (default `0`) and optional `--icon <JPEG path>`. The [map-wide command](MAP_WIDE_FUEL_GENERATOR.md) infers known map names and icons and writes timestamped paths automatically. The first full-map packages used revision `1`; the current missing-price increment defaults to **revision `2`** and produces `1.61-r2-experimental`. The default is a deliberate increment choice, not automatic revision counting. See [CLI examples](TOOLING.md). No stable/release mode or automatic revision increment is implemented. The program's own package version is independent of the generated mod version.

## Handoff filenames

User-facing fuel archives must identify the package family, map and version in the filename as well as the manifest. The historical r0 sample used `szczerbs-road-trip-gas-stations-fix-ats-expansion-1.61-r0-experimental.scs`. Follow `szczerbs-road-trip-gas-stations-fix-<map-slug>-<version>.scs` for subsequent fuel-only handoffs. The CLI accepts an explicit output path; the agent must supply this descriptive name. Current combined map packages use `szczerbs-road-trip-map-fix-<full-map-slug>-1.61-r8-experimental.scs`; for example, `szczerbs-road-trip-map-fix-alaska-expansion-1.61-r8-experimental.scs`. Their mod-manager display name remains `szczerb's Road Trip Map Compatibility Fix for <full source name>`. The longer `...map-compatibility-fix-...` filename belongs to preserved r7 and earlier archives.

**Observed locally — 2026-10-18:** the supplied game log reports a failed cache copy for a missing connector icon. On the inspected Windows mapping, the earlier long archive stem produces a derived cache path about 262 characters long; the shortened combined filename brings the connector path to about 234 characters. A classic Windows path limit is a strong hypothesis for that failure, not a proven engine cause. The shorter filename is a metadata change; in-game icon display remains to be checked. No cache or Windows setting was changed. The [r8/r3 handoff](MOD_METADATA_MAP_NAMES_1_61_R8_R3.md) records package checks and log evidence.

Keep new regeneration copies and their reports in ignored `local_outputs/work/<timestamp>/verification/package-rechecks/`, with descriptive filenames ending in `-recheck.scs` or `-recheck-report.json`. Do not place an ambiguously named verification archive such as `branded-fuel-recheck.scs` beside the deliverable. The historical r0 verification copy was relocated without changing its bytes to `local_outputs/verification/package-rechecks/`; that historical sample remains in `local_outputs/generated/`. New deliverables use `local_outputs/generated/<timestamp>/` under the newer user-requested run-directory convention.

Names are encoded as quoted strings; empty/nonprintable map names, edge whitespace, negative/noninteger revisions and incorrectly framed/sized icons are rejected. JPEG validation checks framing and supported frame dimensions; it is not a full image decoder. Original artwork exports are separately decoded/inspected before handoff. Metadata paths are reserved against gameplay-resource collisions. The embedded report records title, author, version, map, revision and icon SHA-256 separately from the gameplay-resource list. Regeneration is deterministic and refuses to overwrite an existing file.
