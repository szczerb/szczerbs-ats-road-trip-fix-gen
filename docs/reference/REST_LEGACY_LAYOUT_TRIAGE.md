# Legacy rest layout triage

**Observed locally — ATS 1.61.3.18 source stack, 2026-10-18:** Reforma 3.0.1.161 contains three standalone rest polygons with source XZ edge crossings. Two are car actions; the nearby truck action has an original car vertex about two game-world units away. ATS Expansion 23.0 has a car-only standalone polygon with a repeated XZ vertex, a crossed truck standalone polygon, and four garage rest prefabs using PPD versions 23 or 24. Two of those garage truck groups use trigger flags `0x4` on every vertex.

**Documented — [TruckLib.Models `TriggerPoint.cs`](https://github.com/sk-zk/TruckLib.Models/blob/master/TruckLib.Models/Ppd/TriggerPoint.cs), inspected 2026-10-18:** trigger records are 48 bytes and flag bit 2 (`0x4`) is named `PartialActivation`; it activates when the player touches the area border. This independent parser supports the field interpretation but is not an official ATS 1.61 runtime specification.

The rest processor accepts complete, exact PPD v23–v25 trigger sections after descriptor validation. It retargets uniform flags `0` or `0x4` truck groups by replacing only the action token, preserving flags, geometry, topology, and every other byte. Mixed or other flag values remain blockers. Source standalone polygons with a crossing or repeated XZ vertex retain every original geometry and node byte. A car location from such a polygon suppresses a new permission only when an original car/truck vertex pair proves distance within the configured radius.

**Project decision — [ADR-0012](../architecture/decisions/ADR-0012-preserve-irregular-source-rest-geometry.md), 2026-10-18:** polygon topology and interior semantics are needed to measure proximity, but are independent of the validated standalone action-token field. If no vertex pair proves a nearby original car rest, a source truck standalone with finite original vertices and a validated standard truck action is retargeted by changing only the action token. The report records `conservative_proximity_for_irregular_source` for that placement. This can grant an extra car permission where an irregular car polygon's interior was actually nearby; it neither repairs geometry nor claims the exact minimum polygon distance. Unknown activation flags, custom action parameters, invalid action layout, nonfinite positions, and unsupported malformed geometry remain blockers.

**Unknown:** how ATS 1.61 evaluates every malformed source polygon at runtime, whether the accepted historical `PartialActivation` meaning is unchanged, and whether a new car rest action behaves correctly at these sites. Manual rest eligibility and fatigue recovery remain pending.
