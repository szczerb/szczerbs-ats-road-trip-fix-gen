## Tooling and scope

- `generate-map-fix SOURCE --processor fuel --processor rest --experimental` composes selected topics and defaults to revision **5**. Either topic can run alone. Combined outputs use the seven map-specific icons by default; rest-only packages have no default icon. Each fix replaces its source's earlier fix; independently generated sector overrides do not merge. [Processor guide](../reference/COMPATIBILITY_PROCESSORS.md).
- `generate-courier-eligibility --config docs/examples/mustang-practical-courier.toml --experimental` defaults to revision **1** and accepts an explicit `--icon` override. Its default icon and description are separate from map fixes. [Courier guide](../reference/PRACTICAL_COURIER_GENERATOR.md).
- Rest adds car permission locally when no original car area is found within **1,000 game-world XZ units**. The source-sector/halo search is bounded; the user accepts extra permissions from missed boundary neighbors. Shared actions and original geometry remain unchanged; unsupported source edits block publication.
- `generate-map-fuel` retains its fuel-only revision-2 default. Positive petrol values use lower same-unit provenance or the explicit stock-game ratio, preserving diesel/other fields. [ADR-0007](../architecture/decisions/ADR-0007-repair-missing-petrol-prices.md).
- `analyze-map SOURCE --processor courier` remains read-only map-company reporting. General map courier generation is **unsupported**, distinct from the implemented standalone job-class generator. [Reporting](../reference/COURIER_REPORTING.md).
- Archive inspection, selective extraction, context audits and historical bounded samples remain available. [Tool usage](../reference/TOOLING.md).
