# Goal

Deliver a tested Python CLI for archive inspection, courier context analysis, and evidence-supported experimental context/fuel packages, with a reproducible handoff.

# Context

The approved overnight goal authorizes tooling and a PoC after researching both issues. Exact descriptor aliases and GAS flags provide bounded static experiments; runtime eligibility and map-service behavior remain unverified. Design is recorded in [ADR-0002](../../architecture/decisions/ADR-0002-use-python-inspection-and-bounded-experimental-patches.md).

# Scope

- ZIP/HashFS inspection, selective extraction, explicit package order/mounts, include-aware SII analysis, and provenance.
- Context-coverage audit and conservative exact-model/descriptor alias generation.
- PPD v23/v24/v25 inspection and v25-only experimental GAS locator duplication.
- Deterministic new `.scs` outputs with embedded change reports, CLI docs, tests, and static validation against real inputs.
- Exclude live installation, profile edits, full map-sector authoring, broad marker guessing, and gameplay success claims.

# Implementation Plan

1. Implement and test the external HashFS adapter and immutable ZIP reads.
2. Build virtual package/include handling and static courier audit.
3. Implement the two bounded generators with explicit experimental acknowledgement.
4. Exercise CLI paths and actual input packages, compare results with independent research, and verify minimal payloads and preservation.
5. Document supported commands, dependencies, source identities, limitations, generated artifacts, and future copied-profile tests. Commit verified work locally.

# Acceptance Criteria

- The CLI inspects both supplied archive formats, selectively extracts resources, and refuses unsafe paths or replacement of existing outputs.
- Context counts reproduce independent research; unsupported cases are reported without pretending to repair them.
- At least the reviewed `ahorrara` candidate and Reforma `mx9` fuel descriptor can be generated and structurally inspected, with provenance and runtime limitations included.
- Tests cover parser/includes, package order/mounts, alias guards, PPD preservation/idempotence, deterministic packaging, and CLI success/failure paths.
- No game/mod source, live profile, downloaded binary, or copied asset enters tracked source. Usage and remaining validation are documented.
